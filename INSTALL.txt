MindfulFinance — v4.0
=====================
THIRTY measurement items for the whole survey:
   5  social media influence
  15  behavioural bias (5 constructs x 3)
  10  financial well-being
Outside that 30: 3 eligibility checks, 6 About-you items, 2 social media
use items, 1 criterion item, and the optional 5-question knowledge section.

1. Unzip. Copy client/, server/ and tools/ over your project folder,
   keeping the structure. Overwrite when asked.
2. In PowerShell, inside the project folder:
     npm run setup
     npm run build
     git add -A
     git commit -m "v4.0 - 30 items, biases across decision domains"
     git push

WHAT CHANGED
  Biases        10 constructs -> 5, three items each. Each construct now
                spans investing / consumption / saving instead of asking
                the same investing question three ways.
  Headings      construct names hidden; page titles made neutral
  Social media  8 -> 5 items, every one adapted from a published parent
  Feed          "How would I check this?" removed
  Trimmed       platform multi-select, products multi-select
