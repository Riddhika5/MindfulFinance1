MindfulFinance — v3.9
=====================
1. Unzip. Copy client/, server/ and tools/ over your project folder,
   keeping the structure. Overwrite when asked.
2. In PowerShell, inside the project folder:
     npm run setup
     npm run build
     git add -A
     git commit -m "v3.9 - shorter instrument, hidden construct labels, SMI re-scoped"
     git push

WHAT CHANGED
  Biases          34 -> 30 items, exactly 3 per construct, all 10 kept
  Bias headings   construct names no longer shown while answering
  Social media    12 -> 8 items, re-scoped to spending/consumption/saving
                  and to ads, brands and celebrities as well as creators
  About you       "Prefer not to say" removed (those items stay optional)
  api.js          NEW - one place that knows the backend URL, instead of
                  it being hardcoded in ten files

Total scaled items: 48 (8 social media + 30 bias + 10 well-being),
plus 3 social media use covariates and the optional 5-question
financial knowledge section.
